Sponsor Shield privacy policy

Prepared for version 1.6.0 · 15 November 2026

Sponsor Shield mutes and blurs sponsor segments on regular YouTube watch pages, using community-marked segments from SponsorBlock and, when SponsorBlock has none, an AI check of the video’s captions. This policy explains the data the extension uses to do that.

What stays on your device

The extension reads the current YouTube video ID and player state, including playback position, duration, mute state and whether the player reports an ad. It uses these locally to find matching segments, apply the shield and show status. It does not read your general browsing history, record the video or audio, or capture your screen.

Chrome’s local extension storage holds your on/off preference, self-promotion preference, AI-checks choice, the random install ID described below and a running total of sponsor playback time shielded on this device. Apart from the install ID, which is sent with AI checks as described below, these values are not sent to the developer or SponsorBlock, and the extension does not use Chrome storage sync. An old installation may retain an unused legacy playback-mode preference.

Segment choices such as Show anyway are held in page memory until navigation to another video or a reload. A service-worker memory cache holds data for at most 48 videos, with a ten-minute reuse limit. It disappears when Chrome stops the worker. It is not a saved watch-history log.

What is sent to SponsorBlock

To look up segments, the extension computes a SHA-256 hash of the video ID locally and sends only its first four hexadecimal characters to https://sponsor.ajay.app/api/skipSegments/<prefix>. The request also includes fixed category and action-type filters. The complete video ID and page URL are not sent by the extension. Matching the response to the complete video ID happens locally.

As with other internet requests, SponsorBlock and its network providers can see your IP address, request timing and ordinary HTTP connection information. An IP address can indicate an approximate location. A short hash prefix reduces disclosure; it does not guarantee anonymity. Sponsor Shield does not use a location API.

Lookups occur when an enabled watch page needs data. While playback is active in a visible tab, the extension normally checks again about every three minutes. A first empty result can cause an earlier recheck after about a minute. Errors delay further requests. Turning the shield off stops new lookups, though a request already in progress can finish.

Requests use HTTPS and omit credentials. Sponsor Shield sends no account details, cookies, playback positions, votes, submissions, viewing reports, preference values or shielded-time totals to SponsorBlock. SponsorBlock is a separate service; its own privacy practices govern its server logs and retention. This extension cannot delete or set a retention period for those logs.

What is sent to the Sponsor Shield server

AI checks are off until you turn them on, on the welcome page shown after installation or with the AI checks switch in the popup. While they are off, nothing is sent to the Sponsor Shield server. When they are on and SponsorBlock has no sponsor segment for a video, the extension asks the Sponsor Shield server (https://sponsor-shield.spectrumailabs.com, run by the developer) whether it already has an answer, sending the video ID.

If the server has no answer yet, the extension briefly turns on the video’s captions out of sight, reads them, and puts your caption setting back as it was. It then sends the video ID, the caption text with its timings, the caption language, the video’s public description, whether YouTube shows its “Includes paid promotion” label, and a random install ID that the extension makes on first use. The install ID is not linked to your Google account or any other identity; it only lets the server tell different installations apart.

The server sends the caption text, title and description to DeepSeek, an AI provider, to find paid sponsor parts. DeepSeek’s own privacy practices govern its processing. The server also asks YouTube’s public oEmbed service whether the video exists; that request comes from the server and carries nothing about you.

The server stores the answer (sponsor start and end times and brand names), a one-way fingerprint of the captions it was based on, and one-way codes made from the install ID and from your network (the first three parts of an IPv4 address, or the first 48 bits of an IPv6 address). It does not store caption text, IP addresses or install IDs. The codes are used only to confirm that several different viewers saw the same captions before an answer is shared, and to apply rate limits. They are deleted together with the answer they confirm. Server logs record which address path was used, the result and the time taken, not IP addresses.

Requests use HTTPS and omit credentials. Like any web server, the server and its network providers see your IP address while a request is handled.

Data use and sharing

The extension has no analytics, advertising or telemetry SDK. It does not sell user data. Data is used only to provide the described sponsor shielding, settings, status and local time total. The only automatic external data requests made by the extension are the SponsorBlock segment lookup and the Sponsor Shield server requests described above.

Sponsor Shield’s use and transfer of user data follows the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is not used for advertising, unrelated profiling, creditworthiness or lending decisions. No remote code is downloaded or executed: SponsorBlock and Sponsor Shield server responses are parsed and checked as data.

Permissions

  • storage saves local settings and the shielded-time total.
  • activeTab is retained for access associated with opening the popup on the current tab.
  • scripting inserts packaged scripts and styles into already-open supported tabs after installation or an update.
  • Access to youtube.com and www.youtube.com lets the extension find and change the player on supported watch pages, including navigation within the site.
  • Access to sponsor.ajay.app permits segment lookups.
  • Access to sponsor-shield.spectrumailabs.com permits the AI answer requests described above.

Your controls and deletion

You can turn AI checks on or off at any time, turn shielding off, opt in or out of self-promotion shielding, or choose Show anyway for a segment. Chrome’s extension settings let you restrict site access or disable the extension. Removing the extension from Chrome removes its local extension storage; reinstalling starts with the default settings. The extension does not provide a separate reset-total button. Ordinary operating-system or browser-profile backups are outside its control.
